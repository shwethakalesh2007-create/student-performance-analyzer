# student-performance-analyzer:)
A Python-based Student Performance Analyzer that reads student data from a CSV file and displays results with graphs.
## Features :)

- Reads student marks from a CSV file
- Calculates student averages
- Assigns grades
- Shows PASS or FAIL status
- Finds the top-performing student
- Creates graphs for student performance
- Uses Pandas, NumPy and Matplotlib

## How to Use :)

1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Make sure Python and the required libraries are installed.
4. Run `student_performance.py`.
5. The program reads the data from `students.csv`.
6. View the results and generated graphs.
